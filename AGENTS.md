# Project instructions

Preserve the established green and cream design. This is a static HTML/CSS/JavaScript site; do not add a framework or dependencies without a concrete need.

Research categories, in order: Computational statistics and optimization; Compositional data analysis; Microbial data science; Single-cell data science; Statistical oceanography. Each Research paper belongs to exactly one category, newest first, with year beside the title and a source-linked snapshot. Student Projects use paper-title groups, not year groups. Publications remain grouped by year from 2021 onward.

Homepage highlights: Salmonella, Kolb, Score Matching. Keep homepage News. Bakteriopolis belongs in Outreach only. Preserve People spellings and ordering, funding distinctions, course links and proposal links.

Do not claim the publications are a complete Scholar import. Do not invent dates, links, author details or figures. Preserve provenance.

Run `npm run check` after edits. Inspect the affected pages in a browser when possible. Publishing to the live GitHub Pages website is a separate action; do not publish automatically.
